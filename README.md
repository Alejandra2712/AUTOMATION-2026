# Automatización QA - Saucedemo

Proyecto de automatización con Python para el curso de Talento Tech.

## Tecnologías usadas
-Python
-Selenium
-PYtest
-Git
-Github

## Instalación

Instalar las dependencias:

```Python
pip install selenium
```
```Python
pip install pytest-html
```
## Ejecutar las pruebas
```python
pytest
```
## Casos de prueba
-Login exitoso
-Agregar producto al carrito 
-Verificar producto al carrito
